# 贝叶斯概率量化

> 从 SKILL.md 外移。debono 存活条件的定量概率评估协议。

存活论证不应停留在定性层面——"这个命题在条件 X 下成立"不够，还需要回答"条件 X 发生的概率是多少"。

## 量化步骤

1. **列出存活条件**：从存活条件中提取所有独立前提
2. **估计先验概率**：为每个条件估计 P(条件满足)
   - 若 bayes 报告可用（pipeline 模式），优先使用 bayes 验证过的预测作为先验
   - bayes 未覆盖的条件，由 debono 自行估计，标注「未验证先验」
3. **计算期望存活概率**：
   - 独立条件：P(存活) = P(C₁) × P(C₂) × ... × P(Cₙ)
   - 条件依赖：使用条件概率 P(存活) = P(C₁) × P(C₂|C₁) × P(C₃|C₁,C₂) × ...
4. **标注不确定性**：每个概率附注置信水平（高/中/低），低置信条件标记为后续 bayes 验证候选

## 与 problem_type 的关系

| problem_type | 概率量化行为 |
|--------------|-------------|
| deterministic | 条件概率为二元（0 或 1），重点验证条件是否成立而非估计概率 |
| non_deterministic | 全量概率量化，每个条件估计区间概率（如 60-80%），计算期望存活概率 |
| mixed | deterministic 子条件二元判定，non_deterministic 子条件概率量化 |
| pending | 按当前行为执行（定性标注存活条件，不做概率量化） |

## 禁止事项

- 编造精确数字（如 73.2%）——使用区间（如 60-70%）或档位（高/中/低）
- 跳过概率量化直接输出定性结论——quantification 是强制步骤（problem_type=non_deterministic 时）
- 将未验证先验当作已验证结论——未验证条件必须标注
