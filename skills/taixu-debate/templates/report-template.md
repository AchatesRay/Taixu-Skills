# 太虚辩论报告模板（report-template）

> version: 0.8.0
> 约束: 生成 ≤5min、阅读 ≤6min
> 组件: 四组件（辩论精华 + 三区 + 综合判断 + 结论产出）
> v0.7.0: 四轮结构适配（实录第四轮 + 指标口径）+ 分歧归因分类 + 未决类型分类 + 盲区标注记录
> v0.8.0: 概念对齐记录 + 分歧拓扑图（≤1 条分歧时跳过）+ 全场交锋结构图（始终生成）

## 篇幅约束

- 生成时间 ≤ 5 分钟（从 R4 结束到报告输出）
- 阅读时间 ≤ 6 分钟（成人平均阅读速度 300 字/分钟 → 正文总字数 ≤ 1800 字）
- 字数分配参考：辩论精华 ≤150 字 + 综合判断 ≤300 字 = 450 字，三区 + 结论产出 ≤1350 字
- 含四组件：辩论精华 + 三区（共识/分歧/未决）+ 综合判断 + 结论产出
- 不含墓场、认知增量清单等（v2 deferred）

## 双产出定义

每场辩论产出两份文档：

| 产出物 | 文件名 | 阅读时间 | 用途 |
|--------|--------|---------|------|
| 摘要版裁决书 | `taixu-debate-report-<date>.md` | ≤4 min | 快速决策参考 |
| 全程实录汇总稿 | `taixu-debate-transcript-<date>.md` | 15-30 min | 过程回溯、质量审计 |

摘要版 = 本文件"报告结构"定义的辩论精华 + 三区 + 综合判断 + 结论产出（≤1800 字）。
全程实录 = 辩论赛标准格式，含四轮各角色发言全文、西塞罗注记、裁决书内嵌、技术记录。

## 全程实录结构（transcript）

全程实录按辩论赛输出物标准组织，结构如下：

1. **赛事信息**：辩题、日期、赛制、执行模式、角色阵容表（五方立场定位）、立场演化表（轮次×角色，每格≤20字，展示立场变化轨迹。注：本表为创新设计，无外部先例，效果待实际使用验证）、赛制与规则、**概念定义表**（v0.8.0 新增——Phase 0.5 西塞罗统一定义的核心概念，含口径边界）
2. **第一轮：盲立论**：五方立论陈词全文 + 西塞罗注记（隔离有效性、立场分化度）
3. **第二轮：交叉回应**：五方攻辩全文（含 [ref:] 引用标记）+ 西塞罗注记（校验记录、关键事件、**盲区标注**——全场未触及维度清单，只标注不引导）
4. **第三轮：防御/修正**：五方防御/修正全文 + 西塞罗注记（收敛轨迹、有效修正记录）
5. **第四轮：检验交锋与终辩**：各角色开放战线清单 + 有战线角色的两段式发言全文 + R4 沉默角色记录 + 西塞罗注记（开放战线关闭情况、各角色立场终态）；若 R4 未举行（全员沉默或开放战线全空），注明原因
6. **裁决书**：摘要版全文内嵌
7. **数据可靠性审查**：对辩论中被引用的关键外部数据做溯源审查（标注原始来源、口径、可靠度）。西塞罗尝试搜索外部数据后若返回空结果或超时，自动降级为标注引用来源但标注口径未核实。如辩论未引用外部数据，标注“本场无外部数据引用”后跳过。由西塞罗在报告生成阶段执行，计入西塞罗 token 预算
8. **赛事技术记录**：引用校验表（含内容校验列）、沉默记录表、**盲区标注记录**（汇总 #2 标注的盲区 + 是否被 R3/R4 响应）、**概念对齐记录**（v0.8.0 新增——汇总 #1 概念使用检查结果 + R4 后概念定义偏差校验）、收敛轨迹、token 消耗、质量评估指标、本场最佳表现评注。注明"西塞罗与五方角色为同一模型，置信度推断不构成独立判断"。末尾附**全场交锋结构图**（v0.8.0 新增——角色×轮次矩阵，始终生成）

实录中所有发言内容来自真实执行的四轮 subagent 辩论，从本场运行目录 `<run_dir>/`（`runtime/debate/<date>-<topic_slug>-<run_id>/`，定义见 debate-protocol.md「运行目录」节）读取原文，不从会话摘要还原，不做虚构。西塞罗注记由主 agent 在汇总时撰写，不含 LLM 调用。

## 自动润色流程

报告生成后，主 agent 自动调用 **liam-polish** skill 对两份产出物做润色，无需用户确认：

1. **润色范围**：摘要版裁决书 + 全程实录汇总稿
2. **润色目标**：消除 AI 味与翻译腔，提升中文表达地道性，按 liam-polish 四层检测（结构→语言→节奏→灵魂）优化
3. **调用方式**：主 agent 将报告文本传入 liam-polish，Lens 预设选「分析报告」或「通用文档」，Voice 不指定（用默认）
4. **核心信息守恒**：润色可改表达，但事实/数据/结论/引用标记不可丢失或篡改
5. **全自动执行**：中间不向用户提问，liam-polish 的"疑似不静默"原则在自动模式下降级为"标注后继续"，不阻塞流程
6. **润色后输出**：润色版直接覆盖原文件，润色前的原始版不保留（避免文件膨胀）

## 质量评估指标（v0.3.0 新增）

实录的赛事技术记录中增加质量评估指标：

| 指标 | 计算方式 | 目标 |
|------|---------|------|
| 交锋充分度 | R2/R3/R4 非沉默角色比例（R4 分母仅计开放战线非空的角色——制度性沉默不是质量信号） | ≥60% |
| 引用密度 | R2/R3/R4 引用标记总数 | ≥10 |
| 分歧覆盖率 | 分歧区条目数/总条目数 | 15-50% |
| 立场变化率 | R1→R4 立场变化角色比例 | ≥20% |
| 盲区响应率 | 汇总 #2 标注盲区中被 R3/R4 响应的比例 | 记录项，暂不设阈值 |

追问触发率（R3.5 追问触发次数，目标 0-2 次）：自 v0.3.1 起统计，v0.3.0 期间不计入评级。

交锋质量评估（主观维度）：西塞罗对交锋质量做整体评估（充分/一般/不足），评估依据必须引用具体交锋记录。

质量评级：优秀（5 项中 4 项以上达标且交锋质量充分，盲区响应率暂不计入）、良好（3 项）、合格（2 项）、不合格（<2 项）。

指标仅用于事后评估，不反馈到分歧调制机制。以上阈值为初始经验值，首批 3 场实战辩论后校准。

## 面向人读（硬约束）

> 裁决书写给决策者看，不是写给机器解析的。普通人必须能直接读懂。

**摘要版裁决书禁止使用的术语黑话**：
- 「受限域」「三角收敛」「可校验产出闭环」「动机假设可归四族」「权重未收敛」「感知价值裂痕」「存在性收益」「编排层」
- 「未收敛」「已收敛」「收敛程度」「收敛状态」（用"还没定论"/"大家都认可"/"不确定有多大"替代）
- 「立场演化」「叩实」「散怀」「澄源」「破妄」「归真」（太虚体系内部术语，读者看不懂）
- 「命题」「辩题」（报告正文中用"问题"/"这个判断"替代，仅 frontmatter 和标题保留）
- 「预测」「可证伪」「置信度」「先验」「后验」（直接写"我们有没有数据验证这个说法"）
- 「沉默」（指角色选择不发言的机制术语，正文改写为"这一点没有异议"或直接不提）
- 「发言五要素」「EvidencePack」「Phase 0」「subagent」（执行架构术语，不写进报告正文）
- 主持人名「西塞罗」允许出现在全程实录的编辑性内容（注记、赛事信息、技术记录）中；裁决书正文不主动出现（主持人不产出观点）
- 任何需要额外解释才能理解的抽象表述
- 角色名作为主语出现在正文论述中（可放在括号内作注）

**替代原则**：
- 「受限域」→「特定场景」或直接描述场景特征
- 「三角收敛」→「三个角色从不同角度得出同一个结论」
- 「可校验产出闭环」→「产出效果可以验证」
- 「四族」→「四类」
- 「权重未收敛」→「谁占大头不清楚」
- 「未收敛」→「还没定论」或「大家对这点有分歧」
- 「已收敛」→「大家都认可」或「这点没有争议」
- 「置信度高/低」→「比较确定」/「不太确定」/「有数据支持」/「只是猜测」
- 「可证伪」→「能用数据检验的」
- 「叩实/散怀/澄源/破妄/归真」→ 不写进报告，只是角色的内部定位
- 用短句，用口语，用具体例子
- 支撑角色和关键论据融入正文段落，不用「支撑角色:」「关键论据:」标签式列表

**辩论发言层白话化约束**（v0.6.0 新增）：

白话化不只是报告润色，而是从源头控制：每个角色每轮发言必须用普通人能读懂的语言，不依赖 liam-polish 事后纠正。判断标准：把发言给一个非投资/非技术的朋友看，他能否在不查词典的情况下理解每一句话的意思。

**允许使用的结构化元素**：
- 表格：当内容涉及多维关系（如人群×驱动力、权重×角色）时，用表格比纯文字段落更清晰
- 有序列号：当内容有明确顺序（如行动建议步骤）时，用序号列表
- 禁止的仍然是：标签式列表（「支撑角色:」「关键论据:」）、角色名作为标签前缀

**鼓励的表达方式**：
- 类比：用熟悉事物解释陌生概念（如「免费方案是一本好字典，付费方案是一个能干的助手」）。注意：优先为非专业读者使用；对领域专家谨慎使用（类比可能引入误导性映射）
- 具体数字：用实际数据替代抽象描述（如「Cursor 年收入数亿美元」比「收入很高」更有信息量）
- 对比：用对比突出差异（如「Chat 模式你是搬运工，Agent 模式你是审查者」）

**全程实录的豁免**：
- 辩论发言原文保留（那是真实记录，改了就不是辩论了）
- 但西塞罗注记、赛事信息、技术记录等编辑性内容同样遵守面向人读原则

## 报告结构

报告 = frontmatter + 六个正文章节，分四组件：辩论精华（第一组件）+ 三区（第二组件，含共识/分歧/未决三章）+ 综合判断（第三组件）+ 结论产出（第四组件，按命题类型分流）。

### Frontmatter

每份报告的 frontmatter 包含以下字段：

- `辩题`: 辩题陈述原文
- `命题类型`: 投资决策型 | 选择决策型 | 认知求真型（辩题登记时按场景限定 R6 判据判定，决定第六节形态）
- `日期`: YYYY-MM-DD
- `角色`: divergent, convergent, verifier, auditor, integrator
- `轮次`: R1 + R2 + R3 + R4（如中途终止或 R4 未举行，标注实际完成轮次）
- `研究预算`: 轻量 | 标准 | 深度（用户在 Phase 0 选择）
- `证据底座`: 有（附研究工具名称）| 无证据底座（软降级）| 拒绝辩论（投资决策型硬终止）

（执行模式和 token 消耗等元数据放在全程实录的技术记录中，不塞进裁决书 frontmatter）

### 一、辩论精华

> 从四轮辩论中提取的最有穿透力的原话引文。

由西塞罗在报告生成阶段从四轮发言中选取，计入西塞罗 token 预算（非 subagent token）。注：本节为创新设计，无外部先例，效果待实际使用验证。

包含 2-3 条引文，每条带角色标注，每条 ≤50 字。选取标准：要么推翻了某个看似成立的共识，要么提出了一个其他角色都没注意到的角度。必须来自真实辩论发言，不可编造。

如无值得提取的引文，写「无精华：本轮辩论未产出穿透性引文」。

### 二、共识区

> 五角色在辩论后达成一致的论点。

每条共识用自然段落写：先说结论，再说为什么，最后用括号注明哪些角色支撑、关键数据是什么。不用标签式列表。

每条共识增加置信度标注（v0.3.0 新增）：
- **强共识**：≥4 角色支持且无人反驳
- **中共识**：≥3 角色支持，有反驳但被有效防御
- **弱共识**：≥3 角色支持，但反驳未被充分回应

置信度由西塞罗根据交锋记录推断，但括号注明中只放置信度标签本身（如「强共识」），不写「编排层推断」等机制字样。推断属性与依据在全程实录的技术记录中说明，结论报告只呈现标签。

如果共识涉及权重分配（如「四类动机各占多少」），即使无法精确确定，也须给出各角色的估计区间（如「功能型 40-60%」），并标注估计来源（哪个角色的判断、基于什么数据）。不可只写「权重未定」。

推断参考维度（非强制公式）：西塞罗可从以下行为信号推断权重区间——发言篇幅占比、论据计数、反驳强度。行为信号比角色自评更可靠。推断属性在技术记录中说明，裁决书只呈现区间与估计来源角色，不写机制字样（与置信度标注规则一致）。

如无共识，写「无共识：五角色在所有关键论点上均存在分歧」。

### 三、分歧区

> 五角色在辩论后仍未收敛的分歧点。

每条分歧用自然语言写：先说分歧是什么，然后正方怎么说、反方怎么说，最后为什么吵不出结果。角色名放在自然语句中，不用标签。

每条分歧末尾须标注归因类型（v0.7.0 新增，句末括号内白话标注）：
- **价值判断分歧**：双方逻辑链都完整，分歧在取舍偏好——写清「这个分歧只能靠拍板，不能靠数据」
- **数据缺口分歧**：无外部数据可仲裁——须同步在未决区登记验证路径
- **框架边界分歧**：双方在回答不同子问题——写清各自回答的是什么

经 R4 交锋后留存的分歧天然是「交锋后仍开放」，归因标签必须写清为什么交锋后仍吵不出结果，不能只写「开放」。

如无分歧，写「无分歧：五角色在所有关键论点上均已收敛」。

**分歧拓扑图**（v0.8.0 新增，可选元素）：分歧区所有分歧条目之后，由西塞罗在报告生成阶段根据分歧结构绘制 ASCII 图。

跳过条件（F-10 修复）：分歧区为空或仅 1 条分歧时跳过，写「本场分歧结构不适合图示」。

根据分歧结构选择最贴合的形式：

| 分歧结构 | 图示形式 | 适用场景 |
|---------|---------||
| 因果链 | `A → B → C` 链式图，标出分歧节点 | 分歧在某个因果环节是否成立 |
| 二维交叉 | 2×2 矩阵 | 分歧涉及两个维度的交叉 |
| 程度差异 | 光谱轴 `←─────●─────→` | 分歧是程度而非方向 |
| 多力拉扯 | 张力图，标出拉力方向和着力点 | 多个力量互相牵制 |

设计原则：高度概括分歧的**结构**，不复述内容；标出因果链、张力维度、正/负反馈环；用中文白话标签，遵守面向人读原则。ASCII 图不计入正文字数。

### 四、未决区

> 辩论中暴露但因信息不足、验证不可行等原因无法判定的问题。

每条用一句话说问题，一句话说为什么现在答不了，一句话说需要什么才能回答。

每条未决须标注类型（v0.7.0 新增）：
- **数据依赖型**：辩论内部已穷尽（逻辑链无争议，缺的是外部实证），出路是实证验证——必须附验证路径（数据来源/验证方法/预期时间），认知求真型须汇入验证跟踪清单
- **交锋未尽型**：一方质疑或论证在 R4 后仍是他方未回应的开放问题，出路是补充交锋或专项研究——须标注重启触发条件

数据依赖型是常态；交锋未尽型在 R4 后应极少——若大量出现，说明开放战线清单编译有遗漏，西塞罗须在技术记录中说明。

每条未决问题增加验证路径（v0.3.0 新增）：数据来源（具体的数据源）、验证方法（如何验证）、预期时间（预计何时可完成验证）。

如无未决问题，写「无未决问题：所有关键论点均已通过辩论收敛或排除」。

### 五、综合判断

> 报告撰写者补充所有角色未触及的维度。本节为辩论之外的补充视角，非五方共识。

由西塞罗在报告生成阶段撰写，≤300 字。必须有别于三区已有内容（不能是重述）。**只补充新维度，不可修正或否定三区结论。** 面向人读原则同样适用。

如果西塞罗判断没有补充维度，写「无补充」。

### 六、结论产出（按命题类型分流）

> 第四组件的形态由 frontmatter 的 `命题类型` 决定。三类共同要求：结论必须落在三区之上，理由分别引用共识区支撑、分歧区风险提示、未决区后续跟踪。

**投资决策型**（有具体标的与仓位动作），节标题「六、行动建议」：
- **建议操作**: 建仓 / 加仓 / 减仓 / 清仓 / 维持 / 观望
- **理由**: ≤3 句，分别引用共识区支撑、分歧区风险提示、未决区后续跟踪
- **前置条件**: 执行建议操作需要满足的条件

**选择决策型**（技术选型/战略路径/方案取舍），节标题「六、结论与适用边界」：
- **建议结论**: 采用 / 暂缓 / 否决 / 组合（组合须说明各成分的适用条件）
- **适用边界**: 结论成立的条件，以及失效情形
- **理由**: ≤3 句，同上
- **前置条件**: 同上

**认知求真型**（理解现象、检验叙事，无操作动作），节标题「六、结论采纳边界与验证跟踪」：
- **结论采纳边界**: 哪些结论可直接采纳（强共识）、哪些按低置信度参考（中/弱共识）、哪些不可作为依据（未决区条目）
- **验证跟踪清单**: 未决区各条的验证路径汇总（数据来源/验证方法/预期时间），作为后续重检的触发器
- **禁止虚构操作动作**: 认知求真型不产出仓位或执行指令。若辩论暴露了与投资相关的含义，只在「综合判断」节提示，不在本节给出操作建议

> ⚠️ 同上下文扮演降级模式——角色隔离未保证，交锋质量可能受损。

# 太虚辩论报告：加仓 X 公司

## 一、辩论精华

> 贝叶斯：「P/E 低于行业均值 1.5 个标准差，但行业均值本身在压缩，低不等于便宜。」

> 费曼：「用「低估」包装不确定性是自欺。低 P/E 可能是价值陷阱。」

## 二、共识区

**1. X 公司当前估值处于历史低位**

P/E 低于行业均值 1.5 个标准差，这是可验证的硬数据。（黑格尔、贝叶斯、德博诺三方确认。）

**2. 短期催化剂不确定**

新产品发布时间未确认，Q3 财报前没有明确的催化事件。（奥斯本、黑格尔、费曼三方确认。）

## 三、分歧区

**低位是否等于买入机会？**

德博诺认为估值低位加上现金流充足，说明股票被误杀。费曼认为低 P/E 可能是价值陷阱，用「低估」包装不确定性是自欺。吵不出结果的原因是：光看估值无法区分「低估」和「价值陷阱」，需要更多行业数据。

## 四、未决区

**行业竞争格局是否恶化？** 目前缺少竞品市场份额变化的数据，需要查阅最近一期行业报告才能回答。

## 五、综合判断

本节为辩论之外的补充视角，非五方共识。

三方辩论围绕「估值低位是否等于买入机会」，但忽略了一个维度：X 公司的管理层过去三个季度都在减持。如果管理层自己都在卖，「低估」可能意味着市场知道一些辩论中没有触及的信息。

## 六、行动建议

**建议操作**: 观望

1. 估值低位但短期无催化，光看便宜不够
2. 价值陷阱风险未排除，分歧没收敛
3. 需要行业竞争格局数据验证后才能决策

**前置条件**: 行业竞争格局数据验证通过后重新辩论
