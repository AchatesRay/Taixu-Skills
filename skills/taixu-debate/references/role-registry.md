# 角色注册表

> 本文件是 taixu-debate 角色阵容的配置契约：五个辩手角色 + 一个主持人格。
> 角色内容 SSOT = `references/roles/`，辩手 subagent 定义文件由其生成；主持人格无 subagent 定义，由主 agent 扮演。
> 人格命名约定：辩论发言、引用标记、报告中一律使用大师名（奥斯本/黑格尔/贝叶斯/费曼/德博诺），主持人称「西塞罗」；英文 ID（divergent/host 等）仅用于 subagent 类型、文件命名等机器标识。

## 配置契约

### 角色增减规则

- **新增角色**：在 `references/roles/` 下创建 `<role-name>.md` 快照文件，在本注册表追加角色定义，在 U2 创建对应 subagent 定义文件
- **移除角色**：从注册表删除定义，删除快照文件，删除 subagent 定义文件，更新 workflow.js 的 fan-out 列表
- **角色数下限**：3（少于 3 角色无法构成有效辩论）
- **角色数上限**：7（超过 7 角色导致 token 预算不足和交叉回应过载）
- 上下限只约束辩手角色；主持人格（西塞罗）恒定一席，不计入辩手数，不参与立论/回应/沉默机制

### 快照版本管理

每份角色快照含版本注释：
```
> version: 0.1.0
> source_skill: <原子 skill 名称>
> source_version: <原子 skill 版本号>
> extracted: 2026-07-17
```

角色演进时：先改 `references/roles/` 下的 SSOT 快照，再重新生成 `.claude/agents/` 与 `.qoder/agents/` 的 subagent 定义文件。
