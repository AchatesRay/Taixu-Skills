# 验证实验协议

> 本文件是 taixu-debate skill 投入使用前的 go/no-go 验证实验操作手册。
> 实验三要素：独立盲评 + 操作化指标 + 预设阈值。等 token 预算对照。
> 所有阈值与口径在实验执行前锁定，禁止实验后调整。

## 1. 实验目标

验证 taixu-debate 五角色混合盲辩相对于单 agent 同 token 预算直接分析，是否产出**独有且核实为真的新论点**，且盲评胜率达到预设阈值。

**go 判定**：新论点 ≥3 且盲评胜率 ≥60% → skill 投入使用。
**no-go 判定**：任一指标未达标 → skill 保留但标记实验未通过，移除双平台 debate-* subagent 定义文件。

## 2. 实验设计

### 2.1 对照组

- **执行方式**：单个 agent 用与实验组相同的 token 预算，直接分析同一辩题
- **输出**：一份分析报告（不含辩论结构）
- **token 预算**：实验前锁定，记录具体数值

### 2.2 实验组

- **执行方式**：taixu-debate 五角色混合盲辩（R1 盲立论 → R2 交叉回应 → R3 防御/修正 → 报告生成）
- **输出**：三区报告（共识/分歧/未决）+ 结论产出（按命题类型分流）
- **token 预算**：与对照组相同（R8 的 ≤3.5× 基线约束仍适用）

### 2.3 辩题选择

- 选一个真实高 stakes 辩题，属三类命题之一（投资决策型/选择决策型/认知求真型）；投资决策型可从当前持仓或观察仓中选
- 辩题须满足场景限定（R6）：可证伪、有方向性预测或可检验子命题、经过至少一轮 pipeline 收敛
- 辩题与命题类型在实验前锁定，记录到实验报告中

## 3. 盲评流程

### 3.1 盲评载体

盲评由 `debate-blind-judge` subagent 执行。该 subagent 的 system prompt 为中立审查者，只比较两组输出的质量，不分配分组归属。

### 3.2 分组遮蔽

- 对照组与实验组的输出分别标记为"输出 A"和"输出 B"（随机分配）
- 盲评 subagent 不知道哪个是辩论输出、哪个是直接分析
- 分组映射在盲评完成后揭晓

### 3.3 盲评维度（≥3 维）

盲评按以下预设维度逐维判胜负：

| 维度 | 定义 | 判定标准 |
|------|------|---------|
| **信息增量** | 输出中包含的独有论点（对方未覆盖的）数量与质量 | 独有论点更多且经验证为真的一方胜出 |
| **证据质量** | 论点的证据链完整性、来源可靠性、可验证性 | 证据链更完整、来源更可靠的一方胜出 |
| **结论可用性** | 输出对命题所属类型的直接指导价值：决策型命题看结论能否直接转化为行动；认知求真型命题看采纳边界是否清晰可执行 | 结论更具体、更可执行的一方胜出 |

**胜率计算**：胜率 = 胜出维度占比。例如 3 维中胜出 2 维 = 胜率 66.7%。

### 3.4 胜率阈值

- 预设阈值：盲评胜率 ≥60%
- 实验组（辩论输出）胜率 ≥60% → 该指标达标
- 实验组胜率 <60% → 该指标未达标

## 4. 操作化指标

### 4.1 独有且核实为真的新论点计数

**定义**：实验组（辩论输出）中有、对照组（直接分析）中没有的论点，且经核实为真。

**计数流程**：
1. 盲评者标记实验组中的"独有论点"（对照组未覆盖的论点）
2. 主 agent 对每个标记的独有论点进行核实：
   - 联网搜索验证事实性声明
   - 引用 thesis 证据验证投资逻辑
   - 核实为真的论点才计数
3. 记录每个独有论点的核实结果（为真/为假/无法核实）

**阈值**：独有且核实为真的新论点 ≥3 个 → 该指标达标。

### 4.2 token 实测

- 记录对照组与实验组的实际 token 消耗
- 对照 R8 的 ≤3.5× 基线
- 若 workflow 运行时可统计 token 用量，直接记录
- 若不可统计，降级为代理指标（轮次预算上限 + 单轮输出字数上限）+ 事后人工核算总 token 数（从 API 响应 metadata 提取），R8 该维度降级为软约束

## 5. 场景限定

### 5.1 触发条件（R6）

- 命题必须是高 stakes 判断，属三类之一：投资决策型（有具体标的与仓位动作）、选择决策型（技术选型/战略路径/方案取舍）、认知求真型（理解现象、检验叙事）
- 已经过太虚五转 pipeline 至少一轮收敛
- 命题可证伪（含明确的方向性预测；认知求真型允许无具体标的，但须含可检验的子命题）

### 5.2 假命题入场识别清单

**形式化判定标准**：有效命题须含可证伪的正反两方立场——存在一个明确的预测 P，正方认为 P 为真、反方认为 P 为假，且 P 可被外部数据检验。

以下输入应被拒绝：
- [ ] 不可证伪的陈述（如"市场是有效的"）
- [ ] 纯历史回顾无前瞻预测
- [ ] 不可证伪的泛论（如"AI 会改变一切"）；认知求真型辩题允许无具体标的，但须含可检验的子命题
- [ ] 已形成强共识且无分歧空间的命题

## 6. 实验前锁定项

以下项在实验执行前锁定写入实验报告，禁止实验后调整：

| 锁定项 | 值 |
|--------|-----|
| 辩题 | （实验前填入） |
| 命题类型 | 投资决策型 / 选择决策型 / 认知求真型 |
| token 预算 | （实验前填入） |
| 盲评维度 | 信息增量 / 证据质量 / 结论可用性 |
| 新论点阈值 | ≥3 |
| 胜率阈值 | ≥60% |
| 分组映射 | （实验前随机分配，盲评后揭晓） |
